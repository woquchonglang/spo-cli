# spo-cli

a spotify tui app, less is more

need: Spotify Premium

# Feature
os: linux (no windows or macOS)

- [ ] vim key
- [ ] local music
- [ ] animations
- [ ] fullscreen
- [ ] quick start and lazy load
- [ ] mouse
- [ ] config
- [ ] lyrics with autoscroll
- [ ] scope
- [ ] image render
- [ ] desktop notification
- [ ] cross-platform media control
- [ ] home
- [ ] async and multi-thread
- [ ] custom themes

## local music
Audio backend

### meta
.mp3: Audio file with ID3 version 2.3.0, contains: MPEG ADTS, layer III, v1, 320 kbps, 44.1 kHz, Stereo

### lyrics

[Genius](https://genius.com)
